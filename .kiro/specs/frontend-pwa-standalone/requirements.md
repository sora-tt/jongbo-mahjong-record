# 要件定義: frontend-pwa-standalone

## プロジェクト説明

スマートフォンで麻雀記録を利用するユーザーは、ホーム画面に追加したサイトを起動してもブラウザの操作部分が表示され、アプリのように独立して使えない。ホーム画面から起動したときにブラウザのアドレスバーなどを隠し、麻雀記録をアプリ風の画面で使えるようにする。

## スコープと境界

### 対象

- 対応環境でホーム画面アイコンから起動したときの独立したアプリ表示
- iPhone SafariおよびAndroid Chromeでホーム画面に追加するための利用者向け案内
- ホーム画面上でjongboを識別するアプリ名、アイコン、テーマ色
- 端末の切り欠きやシステム操作領域に配慮した表示
- インストール済みWebアプリ内での既存ログインフロー

### 対象外

- オフライン利用、プッシュ通知、バックグラウンド同期
- App StoreまたはGoogle Play向けのネイティブアプリ配布
- Safariとホーム画面Webアプリ間でのログイン状態共有
- 既存のログイン保存期間や認証方式の変更
- Android Chrome以外を含む全ブラウザでの同一インストール動作保証

### 対応環境

- iPhoneはiOS 16.4以降のSafariを対象とする。ホーム画面追加時に「Webアプリとして開く」の選択が表示される場合、利用者が有効にする必要がある。
- AndroidはChromeをstandalone起動の対象とする。
- 対応外のブラウザでも通常のWebサイトとして利用できることを維持する。

## 要件

### 1. ホーム画面からの起動

1.1 When 利用者がiOS 16.4以降のSafariでホーム画面に追加したアイコンを「Webアプリとして開く」設定で起動したとき, the Jongbo web app shall Safariのアドレスバーやタブ操作部分を表示しない独立したアプリ画面で開く。

1.2 When 利用者がAndroid Chromeでホーム画面に追加またはインストールしたアイコンから起動したとき, the Jongbo web app shall Chromeのアドレスバーやタブ操作部分を表示しない独立したアプリ画面で開く。

1.3 When 利用者がホーム画面アイコンから起動したとき, the Jongbo web app shall 通常のサービス入口を開き、既存の認証状態に応じた遷移を行う。

1.4 If 利用者が通常のブラウザー表示でサイトを開いたとき, the Jongbo web app shall ブラウザー操作部分が表示された通常のWebサイトとして利用できる状態を保つ。

### 2. ホーム画面追加の案内

2.1 The Jongbo web app shall iPhone SafariとAndroid Chromeそれぞれでホーム画面に追加する手順を、利用者が確認できるようにする。

2.2 Where iPhoneでホーム画面追加時に「Webアプリとして開く」の選択が表示される場合, the Jongbo web app shall 独立したアプリ画面で起動するためにその選択を有効にするよう案内する。

### 3. アプリの識別と画面表示

3.1 When ホーム画面またはアプリ切替画面にjongboが表示されるとき, the Jongbo web app shall 利用者がサービスを識別できるアプリ名とブランドに沿ったアイコンを表示する。

3.2 Where 端末またはブラウザーがアプリのテーマ色を表示するとき, the Jongbo web app shall 既存のjongboブランドに沿った色を使用する。

3.3 While 独立したアプリ画面が切り欠き、角丸、またはシステム操作領域のある端末で表示されている状態, the Jongbo web app shall 主要な内容と操作部品がシステム領域に隠れず、利用者が操作できる状態を保つ。

### 4. 認証状態

4.1 If 利用者がホーム画面Webアプリ内でログインしていない場合, the Jongbo web app shall 保護された情報を表示する前に既存のログイン手順へ案内する。

4.2 When 利用者がホーム画面Webアプリ内でログインしている状態で起動したとき, the Jongbo web app shall 既存の認証済み利用時と同じサービス入口を表示する。
